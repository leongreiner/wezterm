# `tab_bar_floating_tabs`

*Hivegrid fork only.*

When `true`, the fancy tab bar draws tabs and the "+" button as rounded chips
with all four corners rounded, as tall as the status boxes
([tab_bar_status_scale](tab_bar_status_scale.md)) and centred vertically in the
bar, so their text sits on the same line as the status text. The default
`false` keeps tabs rising from the bar's lower edge.

```lua
config.tab_bar_floating_tabs = true
```
