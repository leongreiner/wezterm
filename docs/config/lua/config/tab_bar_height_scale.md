# `tab_bar_height_scale`

*Hivegrid fork only.*

Height of the fancy tab bar as a multiple of the cell height of the
[window_frame](window_frame.md) font. Defaults to `1.75`. Content is aligned
within the bar: tabs sit on its bottom edge, the status is centred.

```lua
config.tab_bar_height_scale = 2.6
```

See also [tab_bar_status_scale](tab_bar_status_scale.md) and
[tab_bar_separator_height](tab_bar_separator_height.md).
