# `tab_bar_separator_height`

*Hivegrid fork only.*

Thickness in pixels of a line drawn along the edge of the fancy tab bar that
faces the terminal area (the bottom edge, or the top edge when
`tab_bar_at_bottom = true`). It counts towards the bar's height. Defaults to
`0`, no line. Its colour is [tab_bar_separator_color](tab_bar_separator_color.md).

```lua
config.tab_bar_separator_height = 1
```
